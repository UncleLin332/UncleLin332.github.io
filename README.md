# UncleLin332.github.io

個人履歷網站，以 GitHub Pages 架設。

- 網址：https://unclelin332.github.io
- 內容全部在 `index.html`（單檔，純 HTML/CSS，無建置流程）

## 修改方式

編輯 `index.html` 後：

```bash
git add -A && git commit -m "更新履歷內容" && git push
```

推送後約 1 分鐘內自動上線。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可。

## 匯出 PDF

在瀏覽器按 ⌘P 列印，已針對列印做過版面調整。
